# Журнал оценок для родителей

В разделе «Успеваемость» оценки объединены в строки по предметам. Четыре основных предмета всегда показаны отдельно: хореография, фотопозирование, дефиле и актёрское мастерство. Все остальные именованные направления отображаются как отдельные мастер-классы. Например, «Стиль» показан как «МК по стилю», «Визаж» — как «МК по визажу». Явно названный мастер-класс по основному предмету также остаётся отдельным мастер-классом.

В каждой строке находятся все оценки за выбранный период и простой средний арифметический балл. Оценки расположены по датам слева направо; при открытии виден конец строки с последними оценками. Старые оценки доступны при горизонтальной прокрутке. Нажатие на оценку открывает дату занятия и имя педагога; окно закрывается кнопкой или Escape.

Можно выбрать учебный год (с 1 сентября по 31 августа), месяц или всю историю. Текущий учебный год определяется по часовому поясу школы Asia/Irkutsk. Если выбрана вся история и конкретный месяц, показаны оценки этого месяца за все годы. Для предмета без оценок выводится прочерк вместо среднего балла. Пустые и недопустимые значения не превращаются в нули и не участвуют в среднем.

Названия в базе и сами оценки не переписываются. Нормализация касается отображения: регистр, пробелы, е/ё в актёрском мастерстве, прежнее название «Дефиле и подиумный шаг» и варианты префикса МК. Разные темы мастер-классов не объединяются в одну строку.

Для истории оценок используется постраничное чтение по 500 строк с устойчивой сортировкой по дате, времени создания и ID, без ограничения интерфейса последними шестью записями. В родительской модели сохранена исходная ISO-дата. Смена ребёнка сбрасывает выбранный период и открытое окно оценки.

Проверки: `node tests/grade-journal.mjs`, TypeScript и ESLint новых компонентов и модуля группировки. Тест проверяет отдельные темы МК, границы учебного года и месяцев, средние без пустых оценок, сохранение 52 оценок в одной строке и получение истории из 1003 записей через реальный преобразователь данных с подменёнными сетевыми ответами. Данные реальных учеников в тестах не используются.

Визуальная проверка локального экрана в Cloud Browser недоступна: его политика блокирует локальные HTTP- и file-адреса. Сборка проверяется по точному коммиту в Vercel перед публикацией.
