# Уведомления родителям

В кабинете родителя блок «Уведомления на телефоне»: **Включить / Выключить**. Подписка относится к этому устройству и семье, включая нескольких детей. При выходе подписка устройства отключается. Включить уведомления без согласия владельца телефона нельзя.

На iPhone нужна iOS 16.4+ и запуск с экрана «Домой». Звук задаёт ОС; приложение не обходит беззвучный режим, Focus или запрещённые уведомления. На Android и компьютере нужен браузер с Web Push.

## События

Новости используют существующую аудиторию публикации. Оценки, домашние задания, комментарии педагога (в том числе ответ на домашнюю работу) и положительные начисления Star Coin направляются родителям ребёнка. Повторное сохранение неизменной оценки не создаёт уведомления; старые уведомления не рассылаются при первом подключении телефона.

Задолженность проверяется ежедневно в 11:00 по Иркутску. Напоминания отправляются только по начислению с установленным и прошедшим сроком оплаты, максимум раз в семь дней на начисление и родителя. Действительные поступления учитываются независимо от наличного/безналичного способа; отменённые и возвращённые поступления не считаются оплатой. Старую отметку «Оплачено» без суммы не превращаем в долг. Перед отправкой очередь повторно проверяет задолженность и действующий статус ребёнка.

## Развёртывание и поддержка

- Frontend: Vercel, основной домен `open-stars-cabinet.vercel.app`.
- Worker: Supabase Edge Function `parent-push-worker`, исходник в `supabase/functions/parent-push-worker/index.ts`.
- `verify_jwt=false` требуется для вызова из pg_net. Обязательна встроенная проверка `X-Openstars-Push-Key`; RPC дополнительно разрешён только `service_role`. Не удалять эти проверки.
- Секрет диспетчера и закрытый VAPID-ключ находятся в Vault. Они автоматически создаются на сервере, не нужны в Vercel env или клиентском коде. Не выводить и не копировать секреты в отчёты, git или логи.
- Восстановление: применить три миграции `20260911111322`, `20260911111654`, `20260911111958`; развернуть worker; выполнить `update parent_push.config set enabled=true where singleton; select private.pp_wake();`. Не менять VAPID-ключ на работающей установке — телефоны потребуют переподключения.
- Cron `open-stars-parent-push` обрабатывает ожидающую очередь каждую минуту; событие также будит worker сразу. `open-stars-parent-payment-reminders` проверяет долги. История отправок хранится 30 дней, уведомления в кабинете сохраняются отдельно.
- Отключение отправки для обслуживания: `update parent_push.config set enabled=false where singleton;`. Данные занятий и встроенный колокольчик продолжают работать. Очередь старше суток не рассылается после включения.
- Проверка состояния без секретов: `select enabled,public_key is not null as signing_ready from parent_push.config; select state,count(*) from parent_push.deliveries group by state;`. Ответы pg_net — `net._http_response`; смотреть только status_code/error_msg/content, не заголовки запросов.
- Ответ провайдера 404/410 отключает устаревшую подписку; временные ошибки повторяются с задержкой, максимум 6 попыток. Принятие push провайдером не подтверждает показ и звук на конкретном телефоне.

## Проверки

`node --test tests/parent-push-worker.mjs` — показ системного уведомления, звук, защита от повторов и безопасный переход.

`tests/parent-push.sql` — проверки SQL внутри транзакции с rollback. Нужны две действующие семьи; ничего не отправляется на их устройства и не сохраняется в учебных/финансовых данных. Проверки охватывают доступ, события, неизменённые оценки, выбывших, погашение долга, повторы, leases и отключение недействующего устройства.

Worker поддерживает служебный запрос `{"diagnostic":"encryption"}` с внутренним ключом диспетчера. Он проверяет шифрование на синтетическом получателе и ничего не отправляет. Кнопки проверки в родительском интерфейсе нет.
