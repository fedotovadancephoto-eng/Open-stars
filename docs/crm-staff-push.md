# Уведомления CRM OPEN STARS

## Что включено
- При INSERT нового обращения в crm_inbound_items создаются приватные уведомления для владельца, директора проекта, управляющего и отдела продаж; администратор получает только заявки своего филиала.
- Название и текст push **не содержат ФИО, телефон, имя ребёнка или содержание переписки**.
- Используется уже существующий OPEN STARS Web Push (VAPID, Supabase worker, сервис-воркер). Новых платных сервисов нет.
- Пока CRM открыта, счётчик входящих обновляется каждые 20 секунд; новая заявка показывает уведомление внутри приложения.
- При закрытой CRM push работает только после разрешения уведомлений и подписки на конкретном устройстве.
- Повторные записи/доставка обрабатываются существующей очередью parent_push.deliveries; нажатие открывает /admin/crm?inbox=1.
- Маркетолог и родитель не получают CRM push.

## Как включить на телефоне
1. Войти в CRM под рабочей учётной записью.
2. Нажать «Включить на телефоне» в панели «Уведомления CRM».
3. Разрешить системные уведомления.
4. Нажать «Проверить» для тестового push (без персональных данных).
5. На iPhone сначала открыть /admin/crm в Safari, выбрать «Поделиться» → «На экран Домой» и открыть установленную CRM с иконки. Для CRM используется отдельный PWA manifest.
6. Если ранее уведомления были запрещены, разрешить их в настройках телефона/браузера.

## Проверка
- Анонимный пользователь не может вызывать crm_push.
- Вставка синтетического обращения в транзакции создаёт уведомления сотрудникам; откат транзакции не оставляет тестовых данных.
- После подписки устройства тестовый push создаёт уведомление с target=crm_push_test; доставку можно проверить по parent_push.deliveries (state=sent/failed) без чтения endpoint.
- Для реального обращения должна появиться запись в crm_inbound_items и уведомление в public.notifications с target=crm_inbound.
- Если устройство не подписано, push на него не придёт; счётчик внутри CRM продолжит работать.

## Ограничения
- Реальная доставка push зависит от разрешения пользователя, сетевого подключения, настроек энергосбережения и поддержки браузера.
- Не отправлять клиентские данные в push payload.
- Требования к локализации персональных данных российских клиентов должны быть проверены отдельно: Supabase проекта находится за пределами РФ.
